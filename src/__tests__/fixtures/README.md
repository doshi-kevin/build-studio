# Test fixtures — document extraction

Real files used to test the extraction pipeline against the messy real world
(not just synthetic minimal XML). Kept small and license-clean.

## `tables/` — PDF table-extraction fixtures

Purpose-built table PDFs copied from the **camelot-py** test suite
(<https://github.com/camelot-dev/camelot>, MIT License). These are the
library's own synthetic fixtures (not the third-party `tabula/` or
government-data PDFs), so they're safe to vendor under MIT. Each exercises a
distinct table-detection case our lattice/stream detector must handle or defer
to the VLM:

| File | Case |
|---|---|
| `foo.pdf` | canonical clean ruled table (lattice happy path) |
| `column_span_1.pdf` | header cell merged across columns |
| `row_span_1.pdf` | cell merged across rows |
| `background_lines_1.pdf` | ruling lines drawn as background fill |
| `clockwise_table_1.pdf` | rotated (90°) table |
| `missing_values.pdf` | blank cells / gaps |
| `stream_inner_outer_columns.pdf` | borderless, ragged columns (stream case) |

> camelot-py is MIT-licensed (Copyright the Camelot Developers). This subset is
> the library's purpose-built test fixtures; the MIT notice is carried here per
> its terms.

## `office/` — OOXML fixtures

- `gen_chart.xlsx` — a small workbook with an embedded bar chart, **generated by
  this project** (openpyxl) for the extraction experiment. Owned by us; exercises
  real XLSX + native `c:chart` series extraction against an actual Excel binary
  (not hand-rolled XML).
