# Professor Dashboard Components

| File | Purpose |
|------|---------|
| `GradingQueueCard.tsx` | Scrollable list of assignments with ungraded submissions, sortable by longest wait or biggest pile. Rows come from `buildGradingQueue()` in `src/lib/dashboard/professor-todos.ts` |
| `QuickActionsPanel.tsx` | Grid of quick action cards shown on the professor dashboard |
| `CoursePicker.tsx` | Popover for selecting a course section when professor has multiple sections |

Design: `docs/designs/assignments-grading/professor-grading-queue.md`.
