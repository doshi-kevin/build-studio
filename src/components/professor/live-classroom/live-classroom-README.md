# Professor Live Classroom Components

UI components for the professor-side of Live Classroom M1 (PDF Sync).

| File | Purpose |
|------|---------|
| `LivePresenter.tsx` | Fullscreen slide viewer with keyboard navigation (←/→/Space/F), slide counter, and end class button |
| `UploadDeckDialog.tsx` | Drag-and-drop PDF upload with progress indicator, file validation, and retry CTA on failure |
