# Professor Analytics Components

Cross-quiz class analytics displayed in the Grades page Analytics tab.

| File | Purpose |
|------|---------|
| `ClassAnalyticsDashboard.tsx` | Main dashboard layout with summary cards, score distribution, and at-risk students |
| `QuizTrendChart.tsx` | Recharts bar chart showing per-quiz average scores (color-coded by performance) |
| `TopicPerformanceChart.tsx` | Horizontal bar chart showing accuracy per question tag/topic |
